Welcome to terraform-hpc! This is a place where you can find several 
terraform templates to test some small HPC clusters on AWS to learn how
to setup and run HPC instances and jobs. To give some structure to our 
posts, there's a progression of more and more complex deployments we'll
build. Today we'll start with the simplest cluster, a 2-node system with
(1) an admin/login node and (2) a compute node.
